# 因子资料质量与可逆修正

因子目录按研究资料卡、基础价量特征、未完整绑定的指标引用、信号组件分组。默认显示研究资料卡，按名称搜索默认覆盖所有层次。分组不代表收益有效性；基础特征并未被删除。

逐条审阅通过 `graph.factor_quality.import_assessments` 导入本地私有 Catalog。输入必须给出 SHA256，按实体和定义修订绑定。审阅记录追加保存，同版本重导入幂等，同版本不同内容拒绝；不改原始定义、ID、历史研究或个人批注。来源匹配、算子语义、完整可复现合同、数据时点和收益检验分别展示。原始来源无法读取时，相关定义只能以独立阅读参考显示，不替换原式。

Qlib 参数提取应只解析公式的明确时序算子参数。名称尾数不能作为窗口证据。collector与公开快照的后继修订保持一致，单独发布；本次阅读层修正不改冻结原件。四种当根 OHLC 归一化变体中的后缀2不代表滞后2；旧显示由固定源码哈希与原式共同限定的版本化修正覆层处理，保留旧值。当前观测需求1不等于滞后1。多层时序参数不明确时单值摘要为空，完整公式保留。

新资料和审阅资产通过既有不可变批次同步上传，激活前核对定义哈希。Sites 的已发布静态基线必须保持字节不变；后续数据写入 R2/D1 后继批次，代码部署保留原基线身份。没有确认坏项时不归档；更不能把缺少实证当作来源公式损坏。
