# 公开网络来源采集

这里按批次保存从公开上游逐项核对的**实现元数据**：原生 ID、固定版本、来源文件哈希、
逐字段规则、许可证据和缺项。策略实现、因子计算、经济概念分别看待，不因名称相同合并，
不因来源不同就宣称新增经济概念。

每批复用 `metadata/schema.json` 的合同，并有独立 `index.json`、`source-lock.json` 和
`manifest.json`。这是仓库中的知识采集层，未写入活动 Catalog、Site 或原生
normalized/curated 导出。旧 CSV 的 6,971 条仍按原 ID 单独计数，不与实现文件数相加。

公开 Git 仅包含自撰摘要、链接、版本及哈希。非 Qlib 来源原文按项目规则留在忽略的
`datasets/raw/sources/public-web/<批次>/`，保留下载原始字节，不进入 Git。
恢复时只按锁文件的 `fetch_url` 获取同一提交的内容，并同时验证 `sha256` 和 `bytes`；
不得用上游 master、main 或 latest 替换。采集新版本须另建批次，比较变更并审查后再登记。

代码许可只约束相应代码；论文原文和行情数据需另行审核。字段来源、数值计算语义、
经济有效性和商业许可分别登记，源码可读不代表已经取得全部研究数据或证明策略有效。
