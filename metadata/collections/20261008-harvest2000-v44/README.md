**需要复核的四条：**

- **曲率交易：**
  - 买高曲率、卖低曲率的方向取自同一样本（1991–2015）的表 1 面板回归符号，属于样本内定方向，原文没有递推或样本外定方向的结果。
  - 信号用月末零息收益率，成交用月末远期报价，二者不是同一价格，故不按前视处理。原文没有滞后一期执行的结果。
  - k=1 结果最好（夏普 0.56），k 增大后夏普降到 0.36–0.39。2010 年后跑输传统套息，作者归因于零利率下限。
  - 同作者的 ECB WP 2131 只做同一曲率信号的回归，已拒收。
- **PEAD.txt：**
  - 异常收益与高/平/低切点的构造、收益计时都在网络附录，本批未取。
  - 盘后电话会的“第一个收盘”实际是次日收盘，原文正文没有区分盘中与盘后电话会。
  - 数据为 S&P 转录文本（WRDS 订阅），样本只有 2010–2019 年，原文未扣交易成本。
- **货币基差动量：**
  - 这是 Boons–Prado 商品基差动量（M4422）在外汇远期上的同构造，按“市场不同即另起一行”收入。
  - 作者分解显示 BM 与套息、动量高度相关。作者称二者不能完全解释 BM，但 BM 因子对横截面的增量解释力有限。
  - 48 种货币含钉住汇率货币和欧元区旧货币。表 1 注没有逐字写明已扣买卖价，3.2 节写了净收益的算法。
- **MBS PRP：**
  - “每月初”的剩余本金余额依赖机构 MBS 池因子数据，实际在月初数个工作日后才发布，原文没有说明发布时点。市场类型高度持续（约 70% 月份为溢价市场），但用上月余额判定的影响原文没有报告，已写入缺失信息。
  - 国债对冲由 Bloomberg Barclays 用自有提前还款模型计算关键利率久期。
  - 1% 目标波动下月度 α 只有 0.06%–0.08%，原文未扣成本。
  - 仓储条款不允许再分发原文（见下文“许可”）。

## 来源与边界

- **快照锁定：** 每个来源都锁定了原 PDF 的摘要，以及 `pdftotext -layout -enc UTF-8 - -` 派生文本的摘要，生成器版本为 `pdftotext version 25.03.0`。用 `--verify-snapshots` 复核时须使用同一版本。
- **行号与页码：** 字段行号指向派生文本，按 Python `splitlines` 计行；页码是原 PDF 的物理页。
- **执行时点：**
  - 曲率交易与基差动量用月末收益率或汇率计算信号，按远期报价建仓。
  - PEAD.txt 在电话会后第一个收盘建仓，模型和断点只用此前 8 个季度。
  - PRP 用月初余额判定市场类型，波动只用过去值预测；余额的实际发布时滞见上文。
- **已知局限：** PEAD.txt 与 PRP 原文未扣交易成本，曲率交易与基差动量按买卖价计入成本。
- **存储位置：** 公开目录只保存自撰的中文定义和来源证据；论文 PDF 和派生文本留在被忽略的 `datasets/raw/sources/harvest2000-v44/`。
