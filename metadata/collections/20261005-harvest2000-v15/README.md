两条策略的实际执行时点仍为 `MISSING`。双线性策略的初始分配只做一次，不在每期重新分配；持仓上界依赖外部提供的收益界限。论文后续分析中两处符号或金额矛盾已保留，只按明确的账户递推规则收录，不声称证明收益定理。动态交易仅审临时二次冲击与风险矩阵成比例的分支；预测模型、初始份额、交易日历及资金约束仍需另行确定。两者都不是可直接执行的完整账户策略。

五个统计特征各按完整构造计数：

- **Bartlett 检验**：用合并方差与各组方差的对数差衡量方差异质性；保留小样本修正和固定版本先计算尾概率、后截断统计量的顺序。
- **Levene 检验**：比较各组观测偏离组内中心的绝对距离；均值、中位数和截尾中心合为一族。本次固定版本仅对中心计算截尾，偏差与组大小仍使用全部原观测。
- **Alexander–Govern 检验**：按组均值估计误差加权，再将组间偏差作非线性变换后合并；零或接近零的组误差不在已审输入范围。
- **Ansari–Bradley 检验**：按合并排序到两端的对称距离衡量尺度差异；仅审无并列秩的渐近分支，保留统计量和单侧概率的方向约定。源码自动选择精确分支的阈值与文档表述有差异，明确分开记录。
- **Bayesian Blocks**：用常数块似然和每块惩罚，在所有时间分段上求最优分区；事件计数与高斯观测合为一族。保留该版本回溯缓冲区边界，额外限定最终块数小于时间点数；这项使用限制不是源码自动检查，也不是运行验证。

这些统计定义尚未指定金融资产、采样频率和当时可用的数据口径。检验概率不证明预测有效，窗口、参数、单侧方向和多个输出不拆成新条目。Lomb–Scargle 与早期强化学习候选仍有来源或重复性问题，不计入本批。
