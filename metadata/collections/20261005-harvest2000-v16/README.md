# 第十六批来源采集

本批新增 **2 个策略、6 个统计特征**。前十六批累计 105 个策略、172 个因子，1000+1000 的目标仍在进行中，见[采集总览](../README.md)。

| 原生 ID | 已审构造与边界 |
|---|---|
| `multiperiod_portfolio_drawdown` | 由实际净值回撤调整风险惩罚，联合规划多期权重，但每次只执行首期目标；规划中的惩罚不等于实测交易费用，回撤参数也不提供硬性损失上限 |
| `cfmm_routing` | 在多个自动兑换池中联合选择付出与收回的代币数量，要求最后各币净流入非负；协议费纳入池函数，固定链上费用、借款与原子执行仍缺失 |

两项策略都保留实际执行时点 `MISSING`。多期配置使用给定预测，保存已实现的净值峰值；不能将规划权重差当作完整自融资账户账本。多池套利的目标是原单位代币净数量之和，不等于美元利润；最终净流入非负也不保证逐腿交易具备足够资金。它没有自动出售剩余代币的规则。

六个统计特征各按完整构造计数：

- **源汇最大流**：给定有向图和容量，在流量守恒约束下求最大通过量；仅审明确非负整数容量，保留残余图和反向流语义。不同求解算法和最小割对偶不拆计数。
- **最小生成森林**：在给定无向图的每个连通分量中，以无环边集覆盖全部节点并最小化总边权；保留固定实现的排序、同权处理和输入限制。
- **Wilcoxon 符号秩诊断**：对配对差的绝对值排名，再比较正负差的秩量；固定渐近分支，三种零差处理、连续性修正、方向与输出合为一族。
- **Logrank 事件率诊断**：按每个事件时点仍在观察中的人数，比较实际与预期事件数，明确保留右删失；同点删失仍进入该时点风险集。附加样本量和整数宽度限制避免源码计数连乘溢出，概率未做金融校准。
- **时间序列可视图**：按中间观测是否遮挡两端连线构图；自然和水平规则、过去与未来邻居摘要合为一族。固定实现先转 float32，不能把全窗未来节点结果回填到历史时点。
- **事件同步量**：两列二元事件按各事件前后间隔确定匹配容差，保留同刻半计及双向重复修正；仅审显式完整观察时间网格的静态接口，两个方向不拆计数。

图特征尚未指定金融构图或输入；统计与事件特征仍需固定资产、窗口、事件定义、发布时间和数据许可。同名、用途接近、不同参数或语言移植不自动构成新定义。Lomb–Scargle 等存疑候选仍不计数，旧来源的当前版本补证也不新增条目。
