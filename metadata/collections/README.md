每批的 `index.json`、`source-lock.json`、`reviews.json`、`quality-contract.json` 都由 `manifest.json` 固定摘要。规则与公式绑定具体源码或供应商文档行段，去重比较绑定旧记录的 ID、文件与摘要。已经提交的原定义不改写，后续核准项写新批次并登记到统一 `catalog.json`。

因子包括有明确计算定义的技术指标、风险指标、统计特征和链上特征。改变窗口、阈值、资产、周期或输出分量不单独计新；移植、镜像、旧定义新版本、来源不完整与存疑近似也不计新。

仅发布自撰元数据、来源和审核依据；原始源码、网页、论文及详细本机日志不进入 Git。来源审核、计算运行、收益有效性、商业许可分别判断。各批目前均未执行来源代码、计算行情或回测，商业使用状态为 `REVIEW_REQUIRED`。

PDF 来源使用 `pdf.pdftotext-layout`：来源摘要始终指向原始 PDF，`derived_text` 另存派生文本的摘要、字节数、父 PDF 摘要及 `pdftotext` 版本。提取参数固定为 `-layout -enc UTF-8 - -`，本机验证要求同版本工具重新提取后字节一致；公开验证只检查这份证据结构。字段行号指向派生文本，页码用于回看原 PDF。未能可靠提取的图形或公式必须单独保留核验依据，不能因文本提取成功就当作公式已核实。
