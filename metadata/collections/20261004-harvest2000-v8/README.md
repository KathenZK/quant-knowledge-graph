# 第八批来源采集

本批新增 **3 个策略、4 个因子**。前八批累计 82 个策略、113 个因子，目标仍在进行中，见[采集总览](../README.md)。

三个策略均来自作者发布的 TradingView 脚本：五项连续评分的趋势交易、固定价格原点的格线穿越、五条均线百分比斜率排序。已对照源码记录实际入场、退出、数量、费用配置和缺失信息。格线策略的 1R 只是绘图，不是部分止盈；斜率策略的五条均线按变化率排序，不能改写成价格高低排序。Pine v6 默认保证金约束单独引用官方文档，未声称所有信号都会成交。

两个风险测度为三角权预平均方差及核加权滞后收益方差，保留实际单资产输入域、有限样本系数和负值处理边界；核函数、带宽、方向和参数不拆计。两个统计特征为分段统计的慢变化方向及主频相位波动标度，保留全窗口拟合、截尾、白化、有效尺度和退化输入说明。它们只能在观察窗口结束后提取，不能把窗末计算结果回填为窗内当时已知信息。

一个另行复核的加权回归候选与第四批相同脚本、相同版本、相同源码，新增计数为零。近似候选和未决比较项也未借本批转为准入。

[source-lock.json](source-lock.json)固定原件和版本，[reviews.json](reviews.json)保存字段行段、来源补证及比较对象摘要。当前官方依赖文档仅支持默认公式说明，不代表已固定历史运行环境。原文、源码和本机审核日志不进入 Git；没有执行源码、计算行情、回测或验证盈利，商业权利状态仍为 `REVIEW_REQUIRED`。
