## 前视口径（自 v47 起统一）

- **股票月末收盘价：** 用股票月末收盘价（或截至月末的已实现收益）计算信号并按同一收盘价建仓，是学术常规做法。这类结果**可以收**，但必须在记录与本 README 中**标“待复核”**。
- **期权报价中间价或流动性差的价格：** 若信号依赖期权报价中间价，或依赖流动性差的价格（同一时点既算信号又按该价成交，存在买卖价反弹或报价陈旧的偏差），而原文**没有跳过一日的结果**，就**拒收**。
- **其他前视：** 信号窗口跨过建仓时点等情况，仍按严格口径处理：没有可交易日期的结果即拒收。
- **与已提交批次的不一致：** v45 以“信号与建仓用同一月末价格、没有跳一日结果”为由拒收了 Aston OST；v46 的 GW2026 延续臂与 GHK2026 ISKEW 同样是“月末既算信号又建仓、无跳日结果”，却标待复核后收入。从字面看两批口径不一致，特此说明。按要求**不改已提交批次**，统一口径只从 v47 起适用。
  - 按新口径回看，三条已提交的结论都不需要改：
    - Aston OST：v45 拒收理由写明 OST 由期权中间价计算的 delta 对冲收益得出，并按同一月末中间价建仓，没有跳日结果，属于“期权中间价且无跳一日结果”，应拒收，结论不变；
    - GW2026 延续臂：用股票市场月收益，属月末收盘常规，收入并待复核，结论不变；
    - GHK2026 ISKEW：按 v46 README，ISKEW 取自 BMV 作者扩展数据（Boyer–Mitton–Vorkink 预期特异偏度，用股票数据估计，不是期权报价），属股票月末口径，收入并待复核，结论不变。这一点请维护者确认。

**需要复核的两条：**

- **行业明星 ΔEGP（CKMR2026）：**
  - 最近的旧记录是 M6832/M0398，即 Hou（2007）EarnSupBig：把同 FF48 行业市值前 30% 公司的标准化盈余惊喜均值赋给小盘股，在个股层面等权五分位。本条的信号不同：它是前四大明星与非明星的 EGP 加速度之差，在行业层面排序，交易的是行业非明星组合；作者另行控制分析师盈余惊喜后仍显著。
  - 也与客户动量（M4419）、供应商行业动量（M6864）、日频领袖跟随（M3726）作了对比。He–Narayanamoorthy 的个股盈利加速度在 v35–v41 只有“无开放全文”的拒收记录。
  - 主证据见表 11（FF5+MOM，Newey–West 3 阶）：Q5−Q1 月 α 0.725%（t=2.35），样本 1994–2020，共 324 个月。
  - Q1 的 α 在派生文本中印作 0.384，负号缺失；按 Q5−Q1=0.725、Q5=0.341 推断应为负值。
  - 表 11 标题写“sort equal-weighted industry portfolios”，正文写市值加权，两处不一致，待复核。
  - 原文未扣交易成本。同文的明星收益领先滞后组合（表 12，α 0.465%，t=2.41）是另一结果，与 Hou 同族，本批不收。
- **下尾 ΔCIQ 暴露（BN2026）：**
  - 对比了 Kelly–Jiang 尾部风险 β（M4518/M6783）、FF3 特质波动（M4421）、协偏度（M6803/M0387）。本条的信号是残差面板 τ=0.2 分位数因子的创新暴露。作者在 Table 3 的 FF alt. 模型中加入 Herskovic CIV 冲击与 BAB，十分位等权 α 仍为 8.51%（t=4.47）；控制 PCA-SQ 后溢价 6.75%（t=4.26）。
  - 主结果：十分位等权年化 7.41%（t=4.30），市值加权 7.36%（t=2.73）。
  - 用 NYSE 断点时为 6.03%（t=3.80）；限市值大于 NYSE 中位数时降为 4.92%（t=2.33）。
  - 前半样本（1968–1996）只有 4.06%（t=1.72），溢价主要来自 1997 年以后。
  - 依赖 Chen et al.（2021）的迭代分位数因子算法（作者用其 MATLAB 代码），本条未复现。原文未扣成本。
