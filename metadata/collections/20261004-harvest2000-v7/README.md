# 第七批来源采集

本批新增 **7 个策略、9 个因子**。前七批累计 79 个策略、109 个因子；目标仍在进行中，见[采集总览](../README.md)。

策略包括量价分位与均线组合、两类动量分支、突破与均值回归组合、自适应均线与分段退出、二级价格枢轴、历史区间再次突破及订单块确认。已对照实际源码，保留预热不足时的行为、入场挂单与退出单的区别、信号确认时间和持仓限制。有一项 Pine v6 策略使用 300% 权益仓位，却未覆盖默认 100% 保证金要求，暂缓计数；同族规则是否足够独立仍有疑问的候选也不纳入。

9 个因子中，2 个为统计特征：受输入驱动的势阱轨迹、状态近返的局部维与持续性。7 个为风险测度与市场微观结构特征：基准压力后的双锚恢复事件、EDGE 和 Abdi–Ranaldo 价差估计、相邻收益次序截断方差、双幂方差与极化协方差、两尺度单资产方差、ReMeDI 噪声自协方差。每个完整算法族只计一次；AR/AR2、Min/Med、方差与协方差、滞后向量及符号选项均合并登记。

定义保留实现的实际边界：EDGE 默认对估计平方价差取绝对值再开方；AR 的价格窗口对应少一个相邻项；Min/Med 的缺失处理不同；两尺度方差保留源码网格项数与校正系数的差异；ReMeDI 要求输入已经取对数，且用原始样本数作分母。风险事件的恢复耗时只能在恢复时得知，超时和缺口作为删失记录，不能填成零。源码与论文归属分开，不把维护者实现称为原作者亲自编写或已完成论文复现。

[source-lock.json](source-lock.json)固定原件和版本，[reviews.json](reviews.json)保存逐条审核、字段行段及比较对象摘要。同批候选比较绑定最终公开文件。原文、源码和详细本机报告不进入 Git；没有执行源码、计算行情、回测或验证盈利，商业权利单独为 `REVIEW_REQUIRED`。
