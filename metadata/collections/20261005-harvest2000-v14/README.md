# 第十四批来源采集

本批新增 **2 个组合策略、9 个因子与统计特征**。前十四批累计 101 个策略、161 个因子，1000+1000 的目标仍在进行中，见[采集总览](../README.md)。

两个策略均按作者原论文的完整条件配置构造收录：

| 原生 ID | 已审构造与边界 |
|---|---|
| `robust_bond_portfolio` | 对外部给定的利率曲线与利差不确定范围，考虑现金流精确现值的最坏变化及持仓数量调整惩罚；保留每期连续复利单位 |
| `EGM` | 给定风险厌恶参数和联合高斯混合分布，用精确指数效用决定多资产权重；单一高斯退化情形不另计 |

两条策略的调仓频率、交易成本、执行时点均保留 `MISSING`。外部输入参数和完整优化目标不等于已拟合的金融模型或可直接运行的账户策略。稳健债券论文的示例置信度记号冲突保留，未替作者修订示例；指数效用与已有熵风险度量的关系保留，不另计同文风险标量。

九个因子各按完整构造计数：

- **HY 协变差**：按异步观测区间的严格重叠累加增量乘积，不自动插值或修复半正定性。
- **SIML 协方差**：刷新采样后截取半整数余弦基的投影，按刷新轮次配对；只审明确的共同起止与维数范围。
- **Forman 图曲率**：保留维护者三个原生分支为一族；输入权重不得与输出字段冲突。
- **最大权团**：在关系图上寻找两两相连、节点权重和最大的集合；非正权过滤和同权保留规则按源码记录。
- **Qn 稳健尺度**：取所有观测对绝对差的指定阶次，保留实际原生选择算法和校准倍数。
- **双权统计**：中位数与原始 MAD 确定有限支撑权重；位置、方差、尺度、协方差和相关五个输出合为一族。
- **Kruskal–Wallis**：合并排名后比较独立组的秩和差异，保留并列修正与退化边界。
- **Friedman**：在同一对象的多个条件内排名后比较条件效应，保留配对输入要求。
- **Brunner–Munzel**：以跨组秩差的组内离散程度作标准化；统计量与单侧概率的符号约定分别记录。

图特征仍缺金融构图和当时可用信息的定义。统计检验的 p 值不证明金融预测有效，输出、参数、变量对和窗口均不拆成新条目。双权协方差遇零 MAD 的行列可置零，但相关仍可能未定义；Qn 的正校准倍数及数组大小上限属于明确使用范围，不能说成源码已自动检查。
