# 第十三批来源采集

本批新增 **3 个组合策略、7 个统计与图结构特征**。前十三批累计 99 个策略、152 个因子与特征，1000+1000 的目标仍在进行中，见[采集总览](../README.md)。

三个策略按作者原论文的完整组合构造收录：

| 原生 ID | 已审构造与边界 |
|---|---|
| `DENRPO` | 预测收益与组合换手、权重正则共同决定下一期单纯形权重；论文的费用表达和优化惩罚分别保留，未补造实际初始账户 |
| `RCK` | 最大化预期对数增长，并用负幂矩约束限制跌破初始财富阈值的概率；该边界不是相对历史高点的最大回撤 |
| `DRKP` | 对有限概率向量的凸包，最大化最差情景分布下的预期对数增长；不把参数或其它不确定集合拆成新策略 |

RCK、DRKP 的交易成本字段保留 `MISSING`。论文中的抽象资产、情景与每期固定比例配置不等于已确定可交易宇宙、报价时点、求解器和成交方式。DENRPO 的补充代码另存审核证据，不把代码阅读替代论文描述或运行结果。

七个特征各按一个完整构造计数：

- **BDS 诊断**：延迟模板匹配概率相对独立同分布分解的偏离，保留完整窗口与截短窗口的不同用法。
- **medcouple 稳健偏度**：中位数两侧配对核的中位数；只审显式选择的原生旧算法路径，重复中位数的核值按源码处理。
- **Ljung–Box 诊断**：多个滞后的自相关平方和，样本修正与概率自由度分别保留。
- **KPSS 诊断**：去均值累计路径的能量除以长期方差；只审水平平稳路径及其带宽规则，表格插值概率不当作精确分布。
- **ARCH 条件异方差诊断**：平方残差对自身滞后的辅助回归；统计量、F 值和概率输出合计一族。
- **电流介数**：固定正电导无向图中，全通路传输的中介程度；只审完整求逆分支，不等同已有最短路介数。
- **二阶中心性**：通过自环平衡节点强度后，解析计算随机游走回返时间的标准差；只审原生 `weight` 字段路径。

两个图特征缺少金融节点、边权与当时可用数据的生成规则。二阶中心性源文件的 BSD-3-Clause-Clear 条款与共同辅助代码的 BSD-3-Clause 分开标注。统计诊断的概率、输出坐标、窗口、求解器和实现端口均不另计新条目。

[source-lock.json](source-lock.json)锁定来源版本与字节摘要；[reviews.json](reviews.json)保留字段定位、原 PDF 派生与视觉证据、具体旧定义比较及来源缺口。旧 JKP 偏度的来源追索用于比较定义，保留文档与代码有限样本修正的差异；未改写旧记录或放宽原有权利状态。未准入候选的比较另列，计数为零。
