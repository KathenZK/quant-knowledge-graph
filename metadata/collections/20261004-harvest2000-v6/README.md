# 第六批来源采集

本批新增 **6 个策略、11 个因子**。前六批累计 72 个策略、100 个因子；目标仍在进行中，见[采集总览](../README.md)。

策略核对完整信号、入场、退出、仓位和时序，并与旧记录及本轮已收的版本比较。沿用 MACD 主信号而改窗口、过滤和退出配置的一项暂不计新增；UT 同族的一项限价挂单流程候选等待计数口径确认，本批不包含该项。旧源码中停止入场单与退出止损单的区别保留在比较依据中，没有按摘要误认订单用途。

11 个因子均归为统计特征，包括联合非高斯性、时间反演距离、序数网络、双相干、衰减阈值、前缀范围、重标自相关密度、矩阵剖面、复现量化、跨带相位幅度耦合和解析信号包络。每个算法的输出分量、方向、参数和归一结果合并为一个构造。稳健回归依赖尚未完整封闭的 CUSUM 候选暂缓，不拆已知输出补数量。

定义保留实际计算边界：ACF 默认找不到严格负穿越时使用末尾位置；部分实现先截取最早样本，另有实现只对部分统计量截取；矩阵剖面允许匹配窗口内未来片段，所有整窗特征只能在窗口结束后使用。相位幅度耦合的退化输入和包络统计的收缩约定均已列明。实现文件、辅助函数和框架许可分别登记，包括重置随机种子函数的独立许可及全局状态影响。

[source-lock.json](source-lock.json)固定原件和版本，[reviews.json](reviews.json)保存逐条审核、字段行段及比较对象摘要。同批候选比较绑定最终公开文件。原文、源码和详细本机报告不进入 Git；没有执行源码、计算行情、回测或验证盈利，商业权利单独为 `REVIEW_REQUIRED`。
