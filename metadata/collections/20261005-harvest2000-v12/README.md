# 第十二批来源采集

本批新增 **6 个策略、3 个风险与成本特征**。前十二批累计 96 个策略、145 个因子与特征，1000+1000 的目标仍在进行中，见[采集总览](../README.md)。

六个在线组合策略来自固定版本的 OLPS 作者工具库，各完整构造只计一次：

| 原生 ID | 已审构造 |
|---|---|
| `anticor.m` | 相邻历史窗口的相关关系驱动资产间权重转移，按源码合成一层专家 |
| `corn.m` | 按历史路径相关筛选后继样本，优化条件财富乘积 |
| `eg.m` | 上一期目标份额乘收益梯度的指数，再归一化 |
| `ons.m` | 累积梯度与曲率，作受约束的组合投影 |
| `up.m` | 原实现的有限随机链近似组合，不当作精确积分 |
| `cwmr_var.m` | 维护均值与对角不确定性状态，再更新并投影权重 |

资产与价格比的含义来自原工具文档，算法及状态更新来自固定代码，逐字段保留这两类审核状态。ONS 区分优化变量和最终组合；UP 只有十条各五步的随机链且未设种子；CWMR 的判别式分支和投影顺序照实际实现保留。原示例零成本、矩阵列和历史收益不等于已经冻结交易费用、可交易宇宙或当时可用的数据。

三个风险与成本特征为：

- **跨资产与跨期冲击成本**：原论文第 3 节的完整二次成本构造，仅采用原数值例明确的正值系数子范围。保留矩阵平方根、非对角半衰减核及输入单位；不把模型成本称为实际成交成本，也不收录论文中尚有时点疑问的交易策略。
- **BNS 跳跃诊断**：总平方收益与双幂变差之差，以三幂四次变差标准化；只审核固定默认路径。
- **JO 跳跃诊断**：比较简单收益与对数收益形成的交换方差和已实现方差；保留首项零收益、源码样本数与尺度分母，以及说明文字和实际乘除运算的差异。

诊断的统计量、p 值、临界点及内部辅助量属于同一构造，参数、窗口、输出分量和实现端口不拆数量。正态近似与风险用途尚未经过数据验证，不是逐根真实跳跃标签或收益方向证据。

[source-lock.json](source-lock.json)锁定原件版本和字节摘要；[reviews.json](reviews.json)保存字段定位、PDF 派生与视觉证据、具体旧记录比较和来源冲突。只发布自撰定义与证据定位，原始代码、PDF、图页及本机日志不入 Git。论文、工具代码和市场数据的许可范围分别保留。
