# 第十一批来源采集

本批新增 **2 个策略、8 个量化特征**。前十一批累计 90 个策略、142 个因子与特征，1000+1000 的目标仍在进行中，见[采集总览](../README.md)。

两条策略来自原始方法文件：Cboe CALD 用隐含波动率确定看涨期权行权价，并按五批轮换和剩余覆盖预算配置；FTSE WPU 将受 BIS 成交份额约束的最小方差发达货币组合，与 GDP 份额决定的新兴货币及美元分量合成年度篮子。CALD 只审核当前正文构造，历史附录的单位和低波动率边界差异照实保留；WPU 只审核第 4–7 节组合构造，形成日、数量确定日与生效日分开记录。两者仍有数据、模型、求解或成交缺项，不代表完整指数已能复制。

| 特征类别 | 新增 | 内容 |
|---|---:|---|
| 图结构 | 5 | 最短路径介数、接近中心性、Burt 约束度、递归核心数、共同邻居分散度 |
| 分布诊断 | 1 | Epps–Singleton 经验特征函数差异统计量 |
| 金融风险测度 | 2 | 双幂尺度截断协方差、逐前缀刷新与残差投影协方差 |

图特征需要另行定义金融节点、边和时点。节点坐标、归一选项、窗口、输出分量和参数均不拆数量。共同邻居分散度保留锚节点的二跳限制；无向图也不能直接当成对称距离。统计量的协方差归一、小样本修正和固定依赖分别核对。

两种金融协方差均按固定实现记录：阈值法的说明文字与实际平方阈值不同；投影法按完整资产前缀重新刷新，而非照注释套用逐对最小集合。`xts` 差分及外连接语义作为补充依赖参考，未声称还原作者当时的运行环境。离散频数 KL、另一个 KS 实现和退化为共同网格计算的 HY 包装没有增加本批数量。

[source-lock.json](source-lock.json)保留原始版本与摘要；PDF 原件、派生文本、视觉页证据分开核验。[reviews.json](reviews.json)保留来源行段、原文冲突、固定依赖及旧记录比较。只发布自撰定义和证据定位，原始源码、PDF、图页和本机日志不入 Git。
