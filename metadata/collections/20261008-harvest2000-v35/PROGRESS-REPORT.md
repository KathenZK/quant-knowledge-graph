# v35 来源采集进展报告

## 资源获取困难

经过系统性尝试后，遇到以下严重障碍：

### 1. 学术论文获取
- **刘-Stambaugh-Yuan 2019 (中国因子)**：SSRN/宾大仓库均无法稳定下载
- **刘-Tsyvinski-Wu (加密货币因子)**：Yale网站返回HTML而非PDF
- **Moskowitz-Ooi-Pedersen 2012 (时间序列动量)**：ArXiv搜索返回不相关论文
- **Kelly等 (加密货币因子)**：芝加哥大学网站下载失败

原因：大多数学术论文需要机构访问权限或付费下载，公开预印本链接不稳定。

### 2. 中国券商研报
- **聚宽平台**：返回地区限制页面
- **华泰/海通/中信等研报**：无法找到稳定的公开PDF链接
- **中国量化社区**：多数资源需要登录或付费

### 3. 开源项目
- **GitHub因子库**：多数404或返回不完整内容
- **可访问的项目**：因子定义可能与已有OSAP/JKP/Qlib/GTJA191/WQ101重复
