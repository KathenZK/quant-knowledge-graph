策略字段保留各自的描述审核与缺项状态；iForest 核心字段为 `SOURCE_CODE_REVIEWED`，NMF/ICA 为 `SOURCE_DESCRIPTION_REVIEWED`。计算语义均为 `NOT_EXECUTED`，经济有效性均为 `NOT_TESTED`，商用均为 `REVIEW_REQUIRED`。市场及使用用途中的研究假设不晋升为已证实的收益解释。
