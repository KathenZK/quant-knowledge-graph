四条均为来源支持的条件构造。实际市场的数据可得时点、订单和成本合同仍有缺项；原文中的符号或端点说明冲突保留在条目中，没有自行修正文献或验证最优性与收益。

六个统计特征按完整构造计数：

- **DDM**：比较累计二元错误率及其标准误与历史最小界限，保留警告、漂移和下一次输入前重置的区别。
- **EDDM**：跟踪错误事件间距的均值和离散程度，相对历史最大值判断变化；它与 DDM 的状态更新规则不同。
- **FNN**：增加一个延迟坐标后，统计原近邻距离失真的比例；三个相关输出与所有维数共同算一族。
- **Hartigan dip**：用凸、凹经验分布包络衡量单峰形状偏离；保留固定实现的最小值约定，仅收统计量。
- **三节点结构计数**：完整有向图每组三个节点归入 16 种诱导形状，整个计数向量算一条。
- **Moran / Geary 空间相关**：计算给定关系图上节点属性的居中乘积与邻边平方差；两种原生输出保守合为一族，明确规则图上的换算关系。

全部特征仍需研究层固定金融输入、完整窗口、关系图和发布时间。图统计不自动提供市场因果或收益方向；分布检验不保证金融序列上的显著性校准。参数、输出坐标、接口和语言版本不拆计数。
