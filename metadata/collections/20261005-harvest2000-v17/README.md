# 第十七批来源采集

本批新增 **3 个策略、4 个统计特征**。前十七批累计 108 个策略、176 个因子，1000+1000 的目标仍在进行中，见[采集总览](../README.md)。

| 原生 ID | 已审构造与边界 |
|---|---|
| `HighFrequencyTrading` | Avellaneda–Stoikov 有限期近似报价：库存改变双边报价中心，剩余期限与成交强度参数决定价差；不是完整 HJB 精确解，终点按中价估值不代表可以无成本清仓 |
| `ObizhaevaWang13` | 在会逐渐恢复的均匀订单簿中，按给定买入总量和期限，先后两块加中间恒定流完成订单；保留原文符号与状态公式的冲突，不把执行模型当预测收益信号 |
| `prpr0153` | 给定买卖价差，通过边界方程求不交易区：区内保留份数，区外只交易至最近边界；买入与卖出权重分别按 ask、bid 定义，不混成统一中价权重 |

三个策略都缺少真实市场的完整执行合同。做市策略的报价单位、库存和现金状态分别记录；订单执行策略要求给定订单量与期限；不交易区策略仅审原文充分小价差下的无杠杆分支，没有验证数值求解或任意输入下的最优性。原文演示、数学模型费用与实际账户费用分开保留。

四个统计特征各按完整构造计数：

- **Anderson–Darling 多样本诊断**：按合并经验分布的位置对各组累计人数差加权，保留并列值修正、标准化及固定源码的近似概率计算；不同组数和原生分支不拆计数。
- **Page–Hinkley 在线状态**：先更新运行均值，再累计偏差并与累计量历史极值比较；衰减只作用于累计量，触发后的下一次输入前重置。
- **Hoeffding’s D 联合秩依赖量**：用成对样本的边际秩与联合秩形成有限样本修正量；只审完整样本下的统计输出，不声称近似概率或缺失样本分支已通过审核。
- **两序列相干度**：对同频跨谱先按分段求平均，再按两列功率归一；保留显式窗、完整段、去均值与零功率边界，固定实现可能把输入窗数组设为只读。

这些特征仍需研究层固定金融输入、发布时点、采样与窗口。相干度没有因果方向或显著性结论；完整窗口计算不可回填为历史实时信息。相同参数变体、辅助算法和输出坐标不另计。
