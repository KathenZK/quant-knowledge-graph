本批承接 cd2f284（v39），叠加 v40 与 v41 bundle。本批是定向批次，只看三类来源：开放获取或 NBER 的另类数据论文（卫星、网站流量、员工与消费者数据、App 使用、信用卡面板、专利、招聘），公司债、信用与 TRACE 论文，以及作者托管的 2018–2025 年异象论文接收稿。来源取 NBER 官网工作稿、作者教师主页和机构仓储（香港理工大学知识库）托管的论文，不收摘要页、幻灯片或二手转述。所有受阻来源都没有绕过。评估的 18 个候选中收入 3 条，15 条未收，见下文与 `rejected-v42.csv`。

## 去重

每条都检索了 `coverage-map-v42.csv`，同时使用英文和中文关键词，并逐一对照了 v35–v41 集合记录的 ID 清单。检索范围如下：

- 6,971 条 M 记录
- 1,570 个因子变体
- v1–v41 的 440 项
- 11 条已审记录
- v35 的 56 条、v36 的 34 条、v37 的 41 条、v38 的 37 条、v39 的 24 条、v40 的 19 条、v41 的 25 条拒收记录

最近的旧 M 记录钉在 `reviews.json` 的 `compared_rule_pins` 中，同时锁定文件摘要和行摘要。与集合记录的比较只写在去重理由文字中。

判重规则：市场相同且核心信号相同，即视为同一条。

**需要复核的三条：**

- **公司债 ΔImpVOL 与股票 IV 变化：** M6974/M6980/M6981 是对股票本身按 30 天认购、认沽 IV 变化及两者价差排序。本条标的为公司债，信号是 365 天认购与认沽 IV 变化之和；作者显示两者之差对债券没有预测力，因此判为不同市场、不同核心信号。风险调整所用的债券因子由 Turan Bali 提供，属 Bai–Bali–Wen（JFE 2019，已撤稿）体系，α 须谨慎看待；原始十分位收益差（−0.60%，t=3.62）不依赖这些因子。扣成本后只有 100 万美元单笔规模下净收益显著。
- **专利接近度与已收专利信号：** v40 的 InnOrig 衡量所引专利的技术类别广度，TECHRET 是技术相近公司的收益动量，M4285/M6860/M6880 是专利或引用数对研发资本的效率。本条衡量新专利与自身已有技术的重合度，方向不同。加入 UMO 因子后 α 为 0.20%（t=1.71），不显著；样本止于 2008 年。同文的“开发型专利比率”是同一核心信号的另一度量，未单列。
- **对比效应策略：** 原文正文与表 5 注写空头条件为“高于第 25 百分位”，与同段“最高或最低四分位”及反转策略“高于第 75 百分位”不一致，本条按最高四分位记录，期刊终版未比对。按 Breen 等的成本估计，交易成本约等于 α。前视方面，当天公告名单来自事后的 I/B/E/S 实际公告日；大市值公司通常提前数周预告财报日期，作者在网络附录做了 DellaVigna–Pollet 日期调整，所以本条保留并标记，但原文没有“只用事前财报日历”的交易表。

## 产出评估

本批刚好 3 条过线，三类定向来源都已接近枯竭：

- **公司债：** 有开放全文、且未与已收或已拒记录重复的论文几乎没有了。剩下的多属 Bai–Bali–Wen 数据体系（撤稿风险），或已被 Dickerson–Robotti 指出受噪声价格影响。
- **另类数据：** 可得全文多数因样本公司事后确定、数据回溯重建而触发前视；其余只在 SSRN 或付费期刊。
- **2018–2025 异象接收稿：** 大部分已在 OpenSourceAP 或之前批次收录。

继续沿这三个方向采集，预计每批过线不足 3 条。

## 来源与边界

- **快照锁定：** 每个来源都锁定了原 PDF 的摘要，以及 `pdftotext -layout -enc UTF-8 - -` 派生文本的摘要，生成器版本为 `pdftotext version 25.03.0`。用 `--verify-snapshots` 复核时须使用同一版本。
- **行号与页码：** 字段行号指向派生文本，按 Python `splitlines` 计行；页码是原 PDF 的物理页。
- **执行时点：** 三条的 `execution_time` 或 `availability` 都引用了原文的时点说明：Cao 等跳过一天，并处理了 2008 年前 OptionMetrics 收盘价的前视；Fitzgerald 等用 t−1 年已授专利；Hartzmark–Shue 在 t 日开盘建仓。
- **已知局限：**
  - Cao 等：只覆盖发行人有上市期权的债券，α 依赖已撤稿体系的因子，小额交易扣成本后不显著。
  - Fitzgerald 等：样本较旧（1982–2008），原文未做成本测算。
  - Hartzmark–Shue：空头阈值的原文笔误，公告日依赖事后数据，交易成本可能吞没 α。
- **存储位置：** 公开目录只保存自撰的中文定义和来源证据；论文 PDF 和派生文本留在被忽略的 `datasets/raw/sources/harvest2000-v42/`。
